
# Isoko Online Rwanda 🇷🇼

## About the Project

Isoko Online Rwanda is an online marketplace designed to connect buyers and local sellers across Rwanda.

Users can discover products, compare prices, explore shops, and contact sellers directly through WhatsApp.

## Main Features

- Browse products and shops
- Search for products
- Filter products by category
- Display product prices in Rwandan francs (RWF)
- Contact sellers through WhatsApp
- Seller and product registration interface
- Mobile-friendly design

## Future Features

- Secure seller accounts and login
- Shared online database
- Product image uploads
- Protected administrator dashboard
- Monthly seller subscriptions
- Paid product promotion
- Payment verification
- Seller and product moderation

## Technology

- HTML
- CSS
- JavaScript
- GitHub
- Vercel for website hosting

## Project Status

This project is under development. Database integration, secure authentication, administrator controls, and payment processing must be implemented and tested before production use.
