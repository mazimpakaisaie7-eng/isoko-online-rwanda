# Isoko Online Rwanda — launch checklist

- [ ] Run `schema.sql` in the correct Supabase project.
- [ ] Confirm `isoko_stores` and `isoko_products` tables exist.
- [ ] Confirm Row Level Security is enabled and policies are present.
- [ ] Confirm the public `isoko-products` storage bucket exists.
- [ ] Enable Supabase Email authentication and configure site/redirect URLs.
- [ ] Upload the project files to the root of the GitHub repository.
- [ ] Import the repository in Vercel with project root as Root Directory.
- [ ] Deploy the static site (no build command required).
- [ ] Test sign-up, sign-in and sign-out.
- [ ] Register a test store with a valid WhatsApp number.
- [ ] Upload a JPG/PNG/WebP image under 5 MB and publish a test product priced in RWF.
- [ ] Confirm the product is visible publicly and the image loads.
- [ ] Test category filters, search, cart quantity and WhatsApp order enquiry.
- [ ] Test from a second account that sellers cannot edit another seller's listings.
- [ ] Replace/complete Privacy and Terms details and provide a monitored support contact.

Sample catalogue products are display examples only, not verified offers or available stock. Pi checkout is not enabled in this RWF build.
